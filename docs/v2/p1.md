# P1: the learner model and the assist ladder (contracts)

Three pieces are built at once against these contracts. README.md §2 and §4 and algorithm.md §2 and §5 give the reasons
and the numbers; where they disagree, this file wins for P1.

## events.js (exists): what P1 listens to

- `events.on(fn)`, added in P1: `fn(row)` for every row as it's logged. Rows:
  - `{k:'line', id, lv, mode, att, hint, hear, tries, res, stars, alt, ms, clock, perfect?, slip?, self?, counted?, pinyin?, chars?, tried?}`
  - `{k:'card', kind, id, fmt, lv, ms, state, how, out?, stars?, gloss?, reveal?, peek?, like?, replay?}`
- `mode` is one of `speak | self | type | tiles`. `hint` is the help used: 0 none, 1 the frame, 2 the whole answer. `hear` means the model answer was played. `res` is `ok | timeout | skip | cancel`.

## learner.js (new, DOM-free: Node runs it in tools/model-check.mjs and later tools/sim.mjs)

```js
init(data, { store = kv, now = time.now })  // phrases (data.phrases, each {id, level, zh, need, f?}); loads ks.model; listens to events
persona(p)                                   // 'mandarin' | 'dialect' | 'studied' | 'new' | null: the priors (README §2)
skills()                                     // { g, L, S, V, T, R, W }: each { m, s } (mean, sd), θk = g + δk
predict(id, { mode = 'self', assist = 2, typed = 'chars' })  // P(right first time, unhelped beyond the assist) for phrase id
observe(row)                                 // a line or card row (also called through events.on)
level()                                      // { say, listen, read }: 0–5 estimates for badges and the Your Chinese panel
item(id)                                     // { b, s }: the line's current difficulty and its uncertainty
```

**Model** (algorithm.md §2):
- Six skills: L, S, V, T, R, W.
- Loadings w and evidence weight ω per mode. A call moves .3 of each loading to L.
- A typed answer counts twice: once on V (the sound was right) and once on W (the characters were right: not pinyin only, no homophones).
- Outcome y, with the speed adjustment; a self-rated y shrinks 30% toward 0.5.
- The Bayesian-Elo update, and the item prior b⁰. `f` comes from build.py when present (`{level, chars, needGroups, zipf}`); otherwise it's computed from the phrase, with zipf taken as 4.5.
- Mode offsets Δb.
- β per assist level: A0 −0.5, A1 −0.25, A2 0, A3 +0.5, A4 +1.2, A5 +2.5.
- Each day away, every s² grows by 0.01.

**Card rows:**
- A finished scene card with no lookups is a small win on L (calls) or R (others): y = 1, ω 0.1.
- Each lookup, reveal or peek is a small miss: y = 0, ω 0.3, at most 3.

Storage: `ks.model`, under 30 KB.

## assist.js (new)

```js
LADDER                     // A0..A5 (README §4): { clock, help:{hint, free}, prompt:'cue'|'mission', pinyin, english,
                           //   patience, nudges, peekFree, hangup, chaser, leniency, echo }
choose(ps, { last, tau = 0.8 }) // the hardest A whose mean predicted success over phrase ids ps is at least tau, at most one step from last
forCard(scn, { last })     // { A, knobs }: choose() over the scenario's say beats, in the mode the player will answer in
adjust(A, y)               // mid-scenario: y < 0.3 → A+1 (easier); two quick wins (y ≥ 0.9 inside 40% of the clock) → A−1
```

As built: `adjust` is the card's `after(row)`, and `forCard` also takes `hold` (a rung the card stays at, moving nothing:
`#play` holds A2 unless `&A=` says otherwise, and a held story teaches the learner model nothing). At L0, help steps
down as a line is met (content.md): `lineRung()` gives its first meeting A5's help (said first, shown, free), its
second A4's (the frame, free), then the card's rung; an L0 card shows all its English at every rung.

**Who reads the knobs:**
- The Mix and each version's feed put `assist` in `ctx` (`ctx.assist = forCard(scn, …)`).
- Formats pass the knobs to `ask()` as `clockX`, `hint`, `free`, `cue` (no cue when prompt is 'mission') and `echo`.
- call.js reads patience, nudges, peekFree and hangup.
- chase.js reads the chaser multiplier.
- cards.js reads write leniency.
- text.js `zh()`/`en()` use the card's pinyin and English whenever the player's setting is `auto`.

**Settings:** pinyin, english and pressure gain `auto`, the new default. A value the player pins always wins.

**ask():**
- `clockX` multiplies the clock.
- `echo` plays the model answer once at the start, for free.
- With free help (A4, A5), the review credit is capped at 2★ and 1★ (`srs.record`).

**Pinyin by model:** with pinyin on `auto`, a word's pinyin shows while learner P(read w) < 0.8 (algorithm.md §5). This replaces the fixed KNOWN = 6 when the card's pinyin knob is 'model'.

## stretch.js (new) and audio.js

- `stretch(buffer, start, length, rate)` returns a new AudioBuffer: WSOLA, pitch kept, rate 0.6–1.0, cached by key.
- `audio.play(url, a, { rate })` plays through it when rate is under 1. It's used for:
  - A4 and A5 other-character lines (rate 0.85);
  - Hear's slow turn when a beat has no stored slow clip.
- A test compares the duration (length/rate ±3%) and checks the pitch: same dominant frequency ±3% on a synthetic tone.

## The Your Chinese panel (Settings)

Six skills as bars with their uncertainty, the say, listen and read levels, and "based on N lines". Under that, the
persona question, which P3 moves to after the first card.

## Done when (README §11, P1)

- `tools/model-check.mjs` passes. P1 started from "recovers each skill within 0.4 RMSE after 150 lines", but the builder
  showed no estimator can meet that from these lines (each way of answering loads several skills, so their differences
  are barely seen; T needs speech). It now gates on: calibration error ≤ 0.05; mean bias per skill ≤ 0.35 (half a level);
  and error no more than 0.08 above the best any estimator could do with the same evidence. `--strict` prints the old
  target. A say-and-check rating counts 30% less as evidence (SELF): pulling it toward 0.5 read every self-checker
  about half a level low.
- The assist changes at most 2 steps per 5 cards in a simulated run.
- The no-mic and regular test matrices pass; `modes-check` passes.
- Every format honours its knobs: a test per knob.
- v1 behaviour holds at A2 (everything v1 had).
